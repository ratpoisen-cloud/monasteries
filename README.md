# Монастыри (Monasteries)

Веб-адаптация настольной игры «Монастыри». Игроки строят монастыри, собирают ресурсы,
переживают события из колоды Летописи и соревнуются в победных очках.

**Стек:** React 19 + TypeScript + Zustand + Tailwind CSS v4 + Vite 8

---

## Правила игры

### Задача игры

Построить монастырь и набрать наибольшее количество победных очков.

### Подготовка

- Разложите жетоны и карточки по типам рядом с полем.
- Перемешайте колоду «Летопись» (74 карты).
- Каждый игрок ставит фигурку на стартовое место своего цвета.

### Ход игры

Каждый ход состоит из фаз:

1. **INCOME** — получить 1 жетон Молвы.
2. **MOVE** — переместить фигурку на 1 клетку ортогонально (на клетке не может быть другой фигурки).
3. **EVENT_ACTION**:
   - Пустая клетка — взять верхнюю карту Летописи и выполнить её.
   - Клетка с жетоном — выполнить действие жетона (опционально).
   - Город — действие по желанию, карта не берётся.
4. **BUILD** — построить 1 здание (опционально), если хватает ресурсов.

Нельзя оставаться на той же клетке два хода подряд (кроме стартовой клетки монастыря).

### Здания монастыря

Строятся строго по порядку. В один ход — только одно здание.

| Здание | Молва | Монахи | Хлеб | Воск | Особое |
|--------|-------|--------|------|------|--------|
| Кельи | 1 | 1 | 1 | — | — |
| Церковь | 2 | 2 | 2 | 1 | Благословение |
| Стены | 3 | 3 | 3 | — | — |
| Звонница | 4 | 3 | 4 | — | Артель |
| Собор | 5 | 3 | 5 | 2 | Артель + Благословение |

### Ресурсы

- **Молва** — «доброе имя». +1 в начале каждого хода. Не продаётся и не покупается.
- **Серебро** — от карт Летописи или княжеского дара. 1 Серебро = 3 Хлеба или 2 Воска на ярмарке.
- **Соль** — c солеварни (бросок кубика: чёт). 1 Соль = 1 Серебро. Меняется на Хлеб/Воск напрямую.
- **Воск** — от карт Летописи или покупки на ярмарке.
- **Хлеб** — от карт Летописи или с села (бросок кубика: чёт).

### Город

Движение по городу — без карт Летописи. Действия по желанию:

- **Князь** — потратить 5 Молвы, бросить кубик: чёт = +1 Серебро.
- **Епископ** — потратить 4 Молвы, получить Благословение (только если нет текущего).
- **Артель** — заплатить 1 Серебро, получить жетон Артели (сгорает после постройки).
- **Ярмарка** — продать/купить: 3 Хлеба = 1 Серебро, 2 Воска = 1 Серебро, обмен Соли на Хлеб/Воск напрямую.

### Жетоны поля

- **Село** — частный. При установке +1 Хлеб. При посещении — опциональный бросок: чёт = +1 Хлеб.
- **Солеварня** — частный. При установке +1 Соль. При посещении — опциональный бросок: чёт = +1 Соль.
- **Крепость** — общий. Опционально: наём Дружинника за 2 Хлеба.
- **Часовня** — общий. Безопасная клетка. Ставится автоматически при гибели монаха.
- **Ярмарка** — общий. Торговля (городская клетка).
- **Река** — общий. Жетон ставится на **любую свободную клетку поля** по выбору игрока. При уходе бросок кубика: чёт = успех, нечет — остаётесь (уход со следующего хода — без броска).
- **Бурелом** — общий. Непроходим. Жетон ставится на клетку хода, фигурка отступает на клетку, с которой пришла, и ход заканчивается.

Все действия на жетонах — по желанию игрока.

### Монахи

- В монастыре не может быть больше 3 монахов.
- Наём: фигурка на стартовой клетке → потратить 3 Молвы + 1 Хлеб → бросок кубика: чёт = +1 монах.
  Ресурсы тратятся в любом случае, **за ход даётся только одна попытка броска**.
- Гибель: возврат фигурки на старт, -1 карта монаха (если есть), установка Часовни, получение Жития (+1 ПО).
  Житие даётся **только за гибель от кочевников и язычников**; за разбойников — нет.

### Помощники

У игрока не может быть больше одного каждого типа.

- **Дружинник** — наём в Крепости за 2 Хлеба или получение из карты Летописи.
- **Медведь** — получение из карты Летописи.

При опасности (Кочевники, Язычники, Разбойники): бросок кубика → при нечете можно использовать помощника (автоспасение, помощник теряется), откупиться ресурсом или принять смерть монаха.

### Образ и Житие

- **Образ** — от карт Летописи (Отшельник и др.). +1 ПО в конце игры.
- **Житие** — при гибели монаха. +1 ПО в конце игры.
- Реликвии размещаются в ячейках построенных зданий (начиная с Келий).
- При пожаре здание и находящаяся в нём реликвия теряются безвозвратно.

### Окончание игры и подсчёт очков

Игра заканчивается, когда:

- Один из игроков построил Собор (первым).
- Кончилась колода Летописи (74 карты сыграны).

Победные очки:

- Каждое здание (Кельи, Церковь, Стены, Звонница, Собор) = 1 ПО
- Каждый Образ = 1 ПО
- Каждое Житие = 1 ПО

Побеждает игрок с наибольшей суммой.

## Карты Летописи: 26 шаблонов, 74 карты

Колода: каждому шаблону — по 2 копии (52 карты), ещё 22 карты достаются случайно выбранным
шаблонам. Итого 74: у 22 шаблонов в партии 3 копии, у 4 — 2 (какие именно — решает случай).

| Категория | Шаблоны | Примеры |
|-----------|---------|---------|
| `resource_gain` | 7 | Обильный урожай, Бортничество, Щедрые дары, Ярмарочный день, Милостыня князя, Боярский вклад, Чудесное исцеление |
| `resource_loss` | 5 | Засуха, Моровая сырость, Пожар в амбаре, Лютая зима, Разорение путей |
| `place_token` | 5 | Село, Солеварня, Бурелом, Крепость, Речная заводь |
| `monk_death_check` | 3 | Кочевники, Язычники, Разбойники |
| `get_helper` | 2 | Дружинник, Медведь |
| `wildcard` | 3 | Чудотворный Образ, Странник, Встреча с Отшельником |
| `building_destruction` | 1 | Великий пожар |

Подробно: [docs/cards.md](docs/cards.md)

## История изменений

### Initial
- Базовая настройка: React 19, TypeScript, Zustand, Tailwind v4, Vite 8.
- Игровой цикл: карта поля, ходы, фазы INCOME → MOVE → EVENT_ACTION → BUILD.

### Fixes and features

- **Карты Летописи** — 26 шаблонов → 74 карты: получение/потеря ресурсов, установка жетонов, опасности, помощники, образы, пожар.
- **Аудит правил (1)** — исправлено 7 расхождений с оригинальными правилами:
  - Убран reshuffle сброса — карты не возвращаются в колоду.
  - Благословение Епископа — проверка `p.tokens.blessing` перед покупкой.
  - Смерть монаха: `Math.max(0, ...)` позволяет умереть до 0.
  - Артель сжигается после постройки.
  - Бурелом: добавлен `prevCell`, при windfall фишка отступает назад.
  - Подкуп — после броска кубика, а не до.
  - Ярмарка: продажа хлеба/воска за серебро, обмен соли напрямую.
- **Аудит правил (2)** — дополнительные исправления:
  - Стартовые ресурсы обнулены (molva/silver/bread = 0) — правила не дают начальных запасов.
  - Бурелом: после отступления ход заканчивается сразу (без фазы BUILD).
  - Пожар: реликвия привязана к конкретному зданию — сгорает только та, что была в нём.
- **Великий пожар** — механика `building_destruction`, модалка выбора здания; реликвия сгорает вместе со зданием.
- **Локальные шрифты** — EvangelieTT (цитаты), Monomakh Unicode (заголовки), TriodPostnaja (основной текст).
- **Tooltip** — кастомный компонент вместо нативных title (осталась только подпись `title` у названия монастыря).
- **UI** — исправлены тултипы ресурсов, ячейки на доске, исправлено разъезжание клеток.
- **Удалён** неиспользуемый тип клетки `forest`.
- `tsc -b` проходит без ошибок (проверено).

### Аудит (3) — соответствие правилам и блокеры UI

- **Река** — жетон выставляется на любую свободную клетку по выбору игрока (режим выбора прямо на доске),
  а не на клетку хода — приведено к правилам.
- **Житие** — даётся только за гибель от кочевников и язычников; за разбойников монах гибнет без Жития.
- **Постриг** — одна попытка броска за ход (`recruitRolledThisTurn`), кнопка блокируется после броска.
- **Строительство** — проверка по `getNextBuilding`: после пожара цепочка начинается заново с Келий.
- **Опасности** — результат прошлого броска сбрасывается при вытягивании карты: чужое число больше
  не решает судьбу монаха.
- **Князь и Постриг** — guard `diceRolling` до списания ресурсов: повторный клик во время анимации
  броска больше не сжигает ресурсы впустую.
- **Бурелом** — фишка отступает на клетку доски (`hasEntered` не сбрасывается), «двойник» на доске
  и у врат устранён.
- **Колода** — по 2 копии каждому шаблону плюс третья копия 22 случайным шаблонам: те же 74 карты,
  но какие 4 шаблона получат 2 копии, теперь решает случай (раньше смещение было детерминированным).
- **Модалки** — ограничение высоты и скролл: экран победы, Ярмарка, Крепость, пожар и карты «Летописи»
  больше не обрезаются на небольших экранах.
- **CSS** — возвращён фон пергамента (`parchment-bg` → `parchment-codex`), добавлены отсутствовавшие
  `gold-glow`, `gold-border-glow`, `animate-scale-in`, `animate-fade-in`, исправлены несуществующие
  оттенки (`stone-650/750`, `red-850`, `indigo-850`) и `border-double`, цитаты карт набраны EvangelieTT.
- **Сброс состояния** — `initGame` очищает `diceRolling`, очередь выставления жетона и все диалоги.

## Запуск

```bash
npm install
npm run dev
```

Dev-сервер: `http://localhost:5173/monasteries/` (в `vite.config.ts` задан `base: '/monasteries/'`,
поэтому корень `/` отдаёт 404).

## Известные ограничения

- `vite build` может падать с ошибкой Native-binding на Node.js v26 (rolldown).
  Решение: `npm install` переустанавливает бинарники.
- `tsc -b` проходит без ошибок; отдельного скрипта `typecheck` нет (используйте `npx tsc -b`).
- `oxlint` на macOS может не загрузить нативный бинарник, если `node` подписан другим Team ID
  (ошибка «different Team IDs»). Конфиг при этом корректный: `.oxlintrc.json`.
